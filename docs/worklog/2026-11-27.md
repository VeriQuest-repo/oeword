## 사용자에게 보이는 변화
- 외우기에서 방향을 고를 수 있음: '영단어'(영단어 보고 뜻 쓰기), '뜻'(뜻 보고 영단어 쓰기), '영단어/뜻'(카드마다 반반 섞어서) (#45, 이슈 #42)
  - '뜻' 카드는 품사별 단어장 뜻을 보여 주고 영단어를 적게 함. 대문자·소문자와 앞뒤 띄어쓰기는 신경 쓰지 않아도 됨
  - 좁은 폰 화면에서는 방향 버튼이 위아래로 쌓여 글자가 깨지지 않음
- 한 바퀴가 끝나면 틀린 단어만 다시 나오고, 모두 맞힐 때까지 반복함. 결과 화면 제목이 "틀린 단어 N개가 남았어요"에서 모두 맞히면 "다 외웠어요!"로 바뀜. "그만하기"로 멈추면 "외우기를 멈췄어요"가 나오고 남은 단어를 이어서 할 수 있음 (#45, 이슈 #42)
- 외우기가 세 단계로 나뉨: '1. 가리기' / '2. 객관식' / '3. 주관식'. 순서대로 하지 않고 아무 단계나 고를 수 있고, 고른 방향은 세 단계 모두 따름 (#46, 이슈 #43)
  - 가리기: 답 칸을 누르면 뜻이 보이고 다시 누르면 가려짐. 학생이 '외움' / '못외움'을 직접 누르고, '못외움'만 없을 때까지 다시 나옴
  - 객관식: 보기 4개 중 하나를 누르면 바로 맞았는지와 정답(초록)이 보임. '모르겠어요'는 틀린 것으로 봄. 틀린 것만 다시 나옴
  - 고른 Day의 단어가 적으면 같은 단어장의 다른 Day 단어로 보기를 채움. 정답과 뜻이 겹치는 단어는 보기에 넣지 않음. 단어장 전체 단어가 2개보다 적으면 '객관식'을 고를 수 없고 "단어가 2개 이상 있어야 해요"가 보임
  - 폰에서는 보기가 한 줄에 하나씩, 패드에서는 2×2로 놓임
- 단계를 끝까지 마치면(모두 외우거나 맞히면) 완료 기록이 남음. 결과 화면에 "완료 기록을 남겼어요. 외우기 화면의 Day에서 볼 수 있어요."가 나옴. "그만하기"로 멈추면 남지 않음 (#47, 이슈 #44)
  - 외우기 고르기 화면의 Day 버튼에 "가리기 N · 객관식 N · 주관식 N"처럼 단계별로 몇 번 마쳤는지 보임
  - 고른 Day에서 가장 덜 한 단계에 '추천'이 붙고 미리 골라져 있음. 다른 단계를 골라도 됨
  - 보호자는 "누구의 기록을 볼까요?"에서 아이를 골라 기록을 봄. 보호자가 직접 외운 것은 기록에 남지 않음
