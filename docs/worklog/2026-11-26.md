# 2026-11-26

## 사용자에게 보이는 변화
- 단어를 직접 입력할 때 뜻 칸에 `선물, 현재`처럼 쉼표로 적으면, 칸에서 벗어나는 순간 뜻 칸 두 개로 나뉘어 보임. 엑셀 붙여넣기와 같은 규칙이고, 괄호 안 쉼표는 나누지 않음 (`(~에게, ~을) 주다` → 뜻 1개) (#36, 이슈 #34)
  - 입력칸 아래에 "쉼표(,)로 적으면 뜻 칸이 나뉘어요. 괄호 안 쉼표는 그대로 둬요." 안내가 나옴
  - Day 단어 목록에서 뜻 사이가 ` · `로 보여서, 뜻이 하나인지 둘인지 "고치기"를 누르지 않아도 알 수 있음
- 같은 Day에 이미 있는 단어를 또 넣으면 새 단어가 생기지 않고 기존 단어에 뜻이 더해짐. 대소문자는 구분하지 않고, 다른 Day의 같은 단어는 그대로 따로 둠 (#37, 이슈 #35)
  - 직접 입력에서는 "이 Day에 이미 있는 단어예요. 저장하면 아래 뜻을 기존 단어에 더해요."와 지금 뜻이 보이고, 버튼이 "기존 단어에 뜻 더하기"로 바뀜
  - 엑셀 붙여넣기에서는 주황색으로 "이 Day에 이미 있는 단어예요. 저장하면 기존 단어에 뜻을 합쳐요."가 뜨고, 저장 뒤 "N단어 저장했어요. 그중 M개는 이미 있던 단어에 뜻을 합쳤어요."로 알려 줌. 같은 내용을 두 번 붙여넣어도 단어가 늘지 않음
  - 단어를 고칠 때 같은 Day의 다른 단어와 철자가 같아지면 "다른 단어와 같은 철자로는 고칠 수 없어요."가 뜸
- "외우기" 메뉴가 생김. 학생과 관리 권한이 있는 보호자 모두 쓸 수 있음 (#39, 이슈 #7)
  - 단어장과 Day(여러 개)를 고르고 "섞어서 보기"(처음엔 켜짐)를 정한 뒤 "외우기 시작 (N단어)"를 누름
  - 영단어를 보고 품사마다 뜻을 적고 "확인"을 누르면, 품사별로 맞았는지와 단어장 뜻이 바로 보임. "모르겠어요"를 누르면 틀린 것으로 보고 뜻을 보여 줌
  - "다음 카드"로 넘어가고, 중간에 "그만하기"로 멈출 수 있음. 카드에 어느 Day 단어인지 표시됨
  - 끝나면 맞힌 수와 "다시 볼 단어"(단어장 뜻 포함)가 나오고, "틀린 단어만 다시", "처음부터 다시", "범위 다시 고르기"를 고를 수 있음
  - 여러 Day에 같은 단어가 있으면 한 번만 나오고, 어느 Day의 뜻을 적어도 정답
- 채점 규칙이 들어감 (#38, 이슈 #9)
  - 품사마다 뜻 하나만 맞혀도 정답. 띄어쓰기·쉼표·물결(`~`)은 신경 쓰지 않아도 되고, 괄호 부분은 써도 되고 빼도 됨 (`(~을) 주다` → `~을 주다`, `주다` 모두 정답)
  - 한 칸에 뜻을 쉼표로 여러 개 적으면, 적은 뜻이 모두 단어장 뜻이어야 정답. 하나라도 틀리면 틀림
  - `~하다`/`~한` 같은 끝말 차이나 단어장에 없는 비슷한 말은 틀림. "정답으로 인정" 버튼은 없음
- 아이패드에 맞춘 외우기 화면 (#40, 이슈 #8)
  - 가로로 들면 왼쪽에 영단어, 오른쪽에 입력칸. 세로나 폰에서는 위아래로 놓임
  - 입력칸과 글자가 커져 펜슬로 쓰기 편하고, 자동 고침·자동 대문자를 꺼서 쓴 그대로 들어감. Enter는 다음 칸, 마지막 칸에서는 "확인"
  - 화면 키보드가 올라와도 입력칸이 가려지지 않게 화면이 올라감
  - 채점 뒤 입력칸의 초록·빨강 색이 안 보이던 것을 고침
