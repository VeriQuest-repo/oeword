## 사용자에게 보이는 변화
- "단어장" 메뉴가 생김. 단어장 목록에서 새 단어장 이름을 적고 "단어장 만들기"를 누르면 만들어지고, "이름 바꾸기"로 이름을 고칠 수 있음 (#30, 이슈 #4)
  - 다 쓴 단어장은 "보관하기"를 누르면 목록에서 빠짐. 지워지지 않고 "보관한 단어장 보기"를 켜면 다시 보이며 "다시 꺼내기"로 되돌릴 수 있음
- 단어장 안에서 Day를 "Day 추가"로 넣을 수 있음. 번호를 비워 두면 마지막 번호 다음 번호가 붙고, 제목(예: 동물)은 넣어도 되고 안 넣어도 됨 (#30)
  - Day 번호·제목 "고치기", ↑/↓로 순서 바꾸기, "삭제"(한 번 더 눌러 확인. 단어가 있으면 "단어 N개도 삭제"로 알려 줌)
- Day를 누르면 그 Day의 단어 목록과 단어 입력 화면이 나옴. "직접 입력"에서 단어 하나에 품사 여러 개, 품사마다 뜻 여러 개를 넣을 수 있음 ("+ 뜻 추가", "+ 품사 추가", "이 품사 빼기") (#31, 이슈 #5)
  - 품사는 목록(명사·동사·형용사·부사·전치사·접속사·대명사·감탄사·숙어)에서 고르거나 "직접 적기"로 적음
  - 키보드의 Enter(다음)를 누르면 다음 칸으로 넘어가고, 마지막 칸에서 누르면 저장됨
  - "저장하고 다음 단어"를 누르면 칸이 비워지고 단어 칸으로 돌아가, 30단어를 연달아 넣기 쉬움
  - 뜻은 입력한 그대로(괄호·물결 포함) 저장됨
  - 목록에서 단어마다 "고치기"로 그 자리에서 고치고, "삭제"로 지울 수 있음(한 번 더 눌러 확인)
- "엑셀 붙여넣기"로 엑셀에서 단어 · 품사 · 뜻 3칸을 복사해 붙여넣으면 한 번에 여러 단어를 넣을 수 있음 (#32, 이슈 #6)
  - 붙여넣으면 바로 미리보기가 나오고, 같은 단어가 여러 줄이면 한 단어 안에 품사별로 묶임
  - 뜻 칸의 쉼표는 뜻을 나누는 표시로 읽음. 괄호 안 쉼표는 나누지 않음 (`(~에게, ~을) 주다` → 뜻 1개)
  - `n.`·`명`, `v.`·`동`, `adj.`·`형` 같은 품사 줄임말도 알아들음. 머리글 줄, 빈 줄, 맨 앞 번호 칸은 건너뜀
  - 칸이 빠진 줄은 빨간 테두리와 "N번째 줄: 품사 칸이 비어 있어요." 같은 안내가 뜨고 그 자리에서 고칠 수 있음. 고칠 줄이 남아 있으면 저장할 수 없음
  - 이 Day에 이미 있는 단어는 주황색으로 알려 줌(저장은 됨). "고치기"·"빼기"로 줄을 고치거나 뺄 수 있음
  - 한 번에 300단어까지 저장. 하나라도 잘못되면 아무것도 저장되지 않음
- 단어장 만들기·고치기와 단어 넣기는 관리 권한이 있는 구성원만 할 수 있음 (#30~#32)
