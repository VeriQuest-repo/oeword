## 사용자에게 보이는 변화
### 외우기 다듬기 (대표 테스트 2 피드백)
- '가리기'에서 답 칸을 한 번 열어 봐야 '외움' / '못외움'을 누를 수 있음. 열기 전에는 "떠올려 본 다음 먼저 답을 확인해 보세요"가 보임 (#52, 이슈 #49)
- '가리기'에서 두 번째 카드부터 "되돌리기"가 생김. 누르면 바로 전 카드로 돌아가 다시 고를 수 있음 (#52, 이슈 #49)
- Day 버튼의 "가리기 N · 객관식 N · 주관식 N"이 더 크고 진하게 보임. 품사는 작은 회색 기울임 글씨, 뜻은 진한 글씨로 나뉘어 보이고, 객관식 보기에는 품사가 하나여도 품사가 붙음 (#52, 이슈 #49)
- 좁은 폰에서도 "2 / 8", "외움 1" 같은 숫자가 한 줄로 보임 (#52)
- 영단어 아래 스피커 버튼("발음 듣기")을 누르면 영단어 발음을 들을 수 있음. 뜻 보고 영단어 쓰기 카드에서는 답이 보인 뒤에만 나와 정답을 미리 들려주지 않음 (#53, 이슈 #50)
- 외우기 고르기에서 "목록으로 보기"를 누르면 고른 Day의 단어를 번호·영단어·품사별 뜻 목록으로 쭉 볼 수 있음. "모두 보기" / "뜻 가리기" / "영단어 가리기"로 가리고, 가린 칸을 누르면 그 단어만 보임. 돌아가면 고른 Day·방향·단계가 그대로 남아 있음 (#54, 이슈 #51)

### 화면 시험 (4-시험 단계 시작)
- '시험' 메뉴에서 단어장 → Day 여러 개 → 형식('영→한' / '한→영' / '섞기')을 고르고 "시험 시작"을 누르면 범위의 모든 단어가 섞여 나옴 (#55, 이슈 #10)
  - "한→영 문제에 첫 알파벳 보여 주기"를 켜면 입력칸 위에 첫 글자가 보임
  - 시험 중에는 정답을 보여 주지 않음. "이전 문제" / "다음 문제"와 "문제 번호" 버튼으로 아무 문제로나 옮겨 다니고, "채점하기"로 한꺼번에 채점함. 빈 문제가 있으면 한 번 더 눌러야 채점됨
  - 패드 가로에서는 왼쪽에 문제, 오른쪽에 입력칸이 놓임
  - 보던 시험은 기기에 남아 "보던 시험이 있어요"에서 "이어서 보기" / "버리기"를 고를 수 있음
  - 보호자가 본 시험은 채점만 하고 기록에 남지 않음
- 결과 화면에서 문제마다 "내 답"과 "단어장 뜻"(한→영은 "단어장 영단어")을 나란히 보여 줌. 영→한은 품사마다 맞음·틀림을 따로 표시하고, 틀린 문제는 붉은 테두리로 강조함. 빈 답은 "(빈칸)"으로 보임 (#56, 이슈 #11)
  - "틀린 문제만 보기"로 틀린 것만 볼 수 있고, "틀린 단어만 다시 시험 (N개)"로 틀린 단어만 다시 시험 볼 수 있음
  - "지난 시험"에서 회차·날짜·범위·점수를 보고 눌러서 결과를 다시 열 수 있음. 다른 기기에서도 같음. 보호자는 "누구의 시험을 볼까요?"에서 아이를 골라 봄
- "다시 볼 단어": 가장 최근 시험에서 틀린 단어와, 맞혔지만 7일 넘게 안 본 단어가 모임. 다시 맞히면 빠짐 (#57, 이슈 #12)
  - 학생 홈에 다시 볼 단어 수와 "다시 볼 단어 시험 보러 가기" 버튼이 보임
  - 시험 메뉴 맨 위 "다시 볼 단어"에서 목록(틀린 단어는 붉은색)을 보고 형식을 골라 "다시 볼 단어 시험 (N문제)"를 봄. 보호자는 아이의 목록만 봄
  - 외우기 결과는 다시 볼 단어에 들어가지 않음 (화면 시험 기록만 씀)
